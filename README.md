# Telegram-бот для удобства работы с прайс-листами в формате xlsx

### Команды бота:

* /start - приветствие
* /help - краткая подсказка
* /source - выбрать прайс для поиска (по умолчанию прайс для Дрома)
* меню внизу экрана - фильтр поиска по типу товара: «Все» или конкретный тип
* /pf - меню формирования прайсов ([priceformation](https://github.com/vakasyanov81/priceformation)): сформировать общий прайс, обновить прайсы поставщиков, загрузить прайс поставщика, справка
* любое текстовое сообщение - поиск позиции в прайсе

## Установка

Нужен Python 3.14 и [uv](https://docs.astral.sh/uv/). Версия закреплена в `.python-version`, uv подтянет её сам.

В репозитории есть git-сабмодуль [priceformation](https://github.com/vakasyanov81/priceformation) (папка `priceformation/`), поэтому клонируйте вместе с ним:

```bash
git clone --recurse-submodules git@github.com:vakasyanov81/tgbot_price_search.git
```

Если репозиторий уже склонирован без сабмодуля, подтяните его:

```bash
git submodule update --init
```

Обновить сабмодуль до свежей версии: `git submodule update --remote priceformation`, затем закоммитить изменение папки `priceformation`.

Установка зависимостей:

```bash
uv sync
```

## Настройка

1. Создайте файл `autosnab_bot/.env` на основе `autosnab_bot/.env.example`:

   ```env
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   ALLOW_USER_LIST=123456789,987654321
   ```

   * `TELEGRAM_BOT_TOKEN` - токен бота, который выдаёт [@BotFather](https://t.me/BotFather).
   * `ALLOW_USER_LIST` - Telegram ID пользователей через запятую, которым разрешён доступ. Список не может быть пустым, иначе бот не запустится.

2. Не знаете свой ID? Запустите бота, напишите ему любое сообщение: если вы не в списке, он ответит с вашим ID. Добавьте его в `ALLOW_USER_LIST` и перезапустите бота.

## Запуск

```bash
uv run python -m autosnab_bot
```

Бот работает, пока окно терминала открыто. Остановить его можно сочетанием `Ctrl+C`.

## Формирование прайсов (/pf)

Команда `/pf` открывает меню CLI `priceformation` из сабмодуля:

* **Сформировать общий прайс** - запускает `priceformation parse`, присылает лог и готовые файлы из `priceformation/file_prices/result`.
* **Обновить прайсы всех поставщиков** - по очереди выгружает прайсы Запаски, Форточек и МИМ по API и скачивает прайсы из почты, по каждому источнику присылает результат.
* **Загрузить прайс поставщика** - показывает список поставщиков. После выбора пришлите один или несколько файлов (`.xls`, `.xlsx`, `.json`) или zip-архив с ними, каждый до 20 МБ, и нажмите «Загрузить». Файлы раскладывает priceformation по папке `priceformation/file_prices/<код поставщика>/`: имя, которое читает разбор поставщика (например `territories.json` у МИМ, `disk.json`/`tire.json` у Запаски), сохраняется, остальные Excel-файлы становятся `price.xlsx`, `price_2.xlsx`… Одноимённые файлы заменяются, при новых Excel-прайсах прежние удаляются. Передумали - нажмите «Отмена».
* **Справка** - присылает README priceformation файлом.

Одновременно выполняется только одна команда. Логины, пароли и токены для API и почты priceformation берёт из своего файла `priceformation/.env` (см. `priceformation/.env.example`), а настройки поставщиков из `priceformation/parse_config`. Зависимости сабмодуля uv поставит сам при первом запуске.

## Поиск

Бот ищет по прайсам, которые формирует priceformation в `priceformation/file_prices/result`. Берётся самый свежий файл (по дате в имени) выбранного прайса:

| Прайс | Файл | Что показывается |
|-------|------|------------------|
| Прайс для Дрома (по умолчанию) | `price_drom_<дата>.xlsx` | цена, остаток |
| Общий прайс | `price_<дата>.xlsx` | цена, остаток, поставщик |
| Полный прайс | `price_full_<дата>.xlsx` | цена, остаток, поставщик |

Прайс для Дрома и общий прайс формируются через `/pf` → «Сформировать общий прайс». Полный прайс бот не формирует, его можно сделать в priceformation командой `uv run pf parse --result-template for_full`. Отчёт о дублях (`doubles_<дата>.xlsx`) в поиске не участвует.

Выбрать прайс можно командой `/source`. Выбор запоминается для каждого пользователя и сохраняется между перезапусками бота (файл `autosnab_bot/bot_state.pickle`).

1. **Ищите позиции.** Напишите боту часть названия, например `185/65 r15`.
   * Если строка целиком входит в название, показываются все совпадения.
   * Если запрос из нескольких слов, показываются позиции, в названии которых есть все слова (в любом порядке).
   * Одно слово ищется только как точное вхождение в название.
   * Результаты отсортированы по возрастанию цены: из всех совпадений показываются 50 самых дешёвых, в ответе указано общее число найденных. Если у названия несколько строк (например, разные поставщики в общем прайсе), выводится самая дешёвая. Позиции без цены идут в конце.
   * Если ответ не помещается в одно сообщение Telegram (4096 символов), бот показывает столько позиций, сколько влезает.
2. **В ответе указан источник**: какой прайс и какой файл использован, например `Источник: Прайс для Дрома (price_drom_2026-10-20.xlsx)`.
3. **Фильтр по типу товара.** Внизу экрана меню с чипсами: «Все» и типы товара, которые priceformation ставит в прайсы (легковая шина, легкогрузовая шина, грузовая шина, спецшина, мотошина, автокамера, ободная лента, уплотнительное кольцо, диск). Список бот берёт командой `priceformation get_product_types` при запуске и обновляет раз в час. Нажмите на тип — поиск пойдёт только по позициям этого типа, в ответе появится строка `Тип товара: …`, активный чипс отмечен ✅. «Все» снимает фильтр. Фильтр запоминается для каждого пользователя. Меню всегда внизу экрана: бот прикрепляет его к каждому своему обычному сообщению (кроме сообщений со встроенными кнопками, например `/pf` и `/source`, — меню при этом остаётся от предыдущего сообщения). Тип с пометкой `*` в общем прайсе (исправлен priceformation по названию) считается тем же типом.
4. **Запрос можно отредактировать.** Если исправить отправленное сообщение с запросом, бот перепишет свой ответ на него новыми результатами, а не пришлёт ещё одно сообщение. Бот помнит ответы на последние 200 запросов в каждом чате; на более старые он ответит новым сообщением.

Колонки бот находит по заголовкам на листе `price`: «Номенклатура», «Цена», «Остаток» и, если есть, «Поставщик». Когда priceformation формирует новый прайс, бот сам перечитывает файл при следующем поиске.
